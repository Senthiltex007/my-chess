# ♟️ My Chess Game

A simple **terminal-based Chess game** built with Python and ❤️ by Senthil.

---

## 🚀 Features
- Two-player chess (local)
- Detects check & checkmate
- Runs entirely in terminal
- Lightweight and easy to modify

---

- Python 3.8+
- Install dependency:
